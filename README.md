## 🤖 Currently Building

Open-source proofs of concept on running AI agents in production:

- **agent-platform**: a TypeScript / NestJS monorepo for production-grade agents
  - **proto-to-mcp**: expose existing gRPC microservices to AI agents through MCP, with typed tool schemas, auth, per-method permissions and audit logs
  - **durable-runner**: long-running agent jobs on BullMQ + Redis, with retries, idempotency, human approval steps and token budgets
  - **evals-ci**: agent quality as a deployment gate, with versioned eval suites, regression thresholds in GitHub Actions and per-agent rollback
  - **cost-router**: model routing, caching and cost / latency tracking per task
- **fatigue-risk-copilot**: a human-in-the-loop agent for crew roster risk analysis in a regulated domain (synthetic data)
